# Chirpy Social Media

> A full-stack micro-blogging platform built with Go, PostgreSQL, and React — using only Go's standard library `net/http`, no HTTP framework.

**Live:** https://chirpysocial.fly.dev/app/

---

## Features

- **User accounts** — Registration, login, and profile updates
- **JWT authentication** — Short-lived access tokens (1h) + long-lived refresh tokens (60d) with database-backed revocation
- **Argon2id password hashing** — Memory-hard, GPU-resistant (winner of the Password Hashing Competition)
- **Chirps** — Create, read, and delete posts up to 140 characters
- **Profanity filter** — Automatic case-insensitive word replacement using whole-word regex
- **Author-only deletion** — Authorization enforced at the handler level
- **Feed filtering & sorting** — `?sort=asc|desc` and `?author_id=<uuid>` query parameters
- **Premium membership** — Chirpy Red status granted via Polka webhook integration
- **Type-safe SQL** — All queries generated by [sqlc](https://sqlc.dev/) from raw SQL files
- **React frontend** — Feed, login, register, and profile pages built with React + TypeScript + Tailwind CSS

## Quick Start (Docker)

```bash
git clone https://github.com/jamesboder/ChirpySocialMedia.git
cd ChirpySocialMedia

# Start the database and wait for it to be healthy
docker compose up -d db
until docker compose exec -T db pg_isready -U chirpy -q; do sleep 1; done

# Run migrations (000_all.sql only — numbered files are goose migrations, not for direct use)
docker compose exec -T db psql -U chirpy -d chirpy < sql/schema/000_all.sql

# Build and start the API
docker compose up api
```

Verify:
```bash
curl http://localhost:8888/api/healthz   # → OK
```

Frontend: **http://localhost:8888/app/**

> **Note:** Migrations only need to run once. Data persists in the `chirpy_data` Docker volume across restarts. Only re-run if you use `docker compose down -v`.

## API Reference

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| `GET` | `/api/healthz` | — | Liveness check |
| `POST` | `/api/users` | — | Register new user |
| `POST` | `/api/login` | — | Login, receive JWT + refresh token |
| `PUT` | `/api/users` | JWT | Update email/password |
| `POST` | `/api/refresh` | Refresh token | Issue new access token |
| `POST` | `/api/revoke` | Refresh token | Revoke refresh token (logout) |
| `POST` | `/api/chirps` | JWT | Create chirp (max 140 chars) |
| `GET` | `/api/chirps` | — | List chirps (`?sort=asc\|desc`, `?author_id=<uuid>`) |
| `GET` | `/api/chirps/{id}` | — | Get single chirp |
| `DELETE` | `/api/chirps/{id}` | JWT | Delete chirp (author only) |
| `POST` | `/api/polka/webhooks` | API key | Premium upgrade webhook |
| `GET` | `/admin/metrics` | — | Fileserver hit count |
| `POST` | `/admin/reset` | — | Reset DB (dev/`PLATFORM=dev` only) |

## Project Structure

```
ChirpySocialMedia/
├── main.go                        # Entry point: DB init, middleware chain, route registration
├── go.mod / go.sum
├── sqlc.yaml
├── Dockerfile                     # Multi-stage build (Node → Go → alpine)
├── docker-compose.yml             # Local dev: api + postgres
├── fly.toml                       # Fly.io deployment config
│
├── internal/
│   ├── auth/                      # JWT, Argon2id, token helpers
│   │   └── auth_test.go
│   ├── config/                    # Environment loading + startup validation
│   ├── database/                  # sqlc-generated query code (do not edit)
│   ├── handlers/                  # HTTP handlers: chirps, users, auth, admin, webhooks
│   │   ├── mock_test.go           # Shared mock Store for handler tests
│   │   └── *_test.go              # Tests for every handler file
│   ├── middleware/                # CORS, request logging, panic recovery
│   │   └── middleware_test.go
│   └── respond/                   # Shared JSON response helpers
│
├── frontend/                      # React + TypeScript frontend (Vite)
│   ├── src/
│   │   ├── features/              # Auth, chirps, profile pages
│   │   ├── services/api/          # Axios client + endpoint functions
│   │   ├── contexts/              # AuthContext (JWT storage + state)
│   │   └── components/            # Header, ProtectedRoute
│   └── dist/                      # Built assets (served by Go at /app/)
│
└── sql/
    ├── schema/                    # 000_all.sql (complete schema) + goose migrations
    └── queries/                   # SQL consumed by sqlc
```
